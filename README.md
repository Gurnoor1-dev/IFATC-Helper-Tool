# IFATC Helper Tool

A project repository for the IFATC Helper Tool. The repository currently has no committed application files, so setup and deployment commands will depend on the framework added next.

## Start developing
```bash
git clone https://github.com/Gurnoor1-dev/IFATC-Helper-Tool.git
cd IFATC-Helper-Tool
```

Add the application source and its package/dependency manifest before running a development server or production build.

## Deploy from a terminal
Once a runnable app exists, install its documented dependencies and run its build/start commands from the terminal. Commit the deployment configuration alongside the source.

## Deploy on Vercel
1. Import the repository into Vercel.
2. Select the framework after adding the application files.
3. Configure the build and output settings to match that framework.
4. Add required environment variables in Vercel Project Settings, then deploy.

## Security
Do not commit API keys, passwords, tokens, or production environment files.
